# GSTR-2B to Tally Purchase & CDNR Mapper

## Run Locally
```bash
npm install
npm start
```
Open `http://localhost:3000` in your browser.

## Deploy
- **Node.js (Render / Railway)**: Build command `npm install`, Start command `npm start`.
- **Static Hosting (GitHub Pages / Netlify / Cloudflare Pages)**: Serve `public/index.html` directly — all Excel parsing and Tally XML generation run in the browser.
